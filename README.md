# 飞机大战（C++ 控制台游戏）

基于 Windows 控制台 API 实现的飞机大战小游戏，C++ 单文件（约 700 行），无第三方依赖。课程实训项目（2024.07）。

玩家控制战机在 48×24 的字符战场内移动、射击，击毁不断下落的敌机得分；得分达到阈值后等级提升，敌机移动随之加快。支持两种难度、暂停、结算与重新开始。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 上 / 左 / 下 / 右 移动 |
| K | 射击 |
| P | 暂停 / 继续 |
| E | 结束本局，进入结算 |

主菜单：W / S 选择难度，K 确认。

## 功能

- 菜单与难度选择（简单 / 困难，影响敌机移动间隔）
- 战机移动、子弹发射、敌机下落
- 矩形碰撞判定：子弹命中敌机、敌机撞毁战机
- 计分与等级：每击毁一架敌机 +5 分，120 / 360 / 480 分时等级提升
- 暂停、结算、重新开始
- 隐藏光标、局部重绘，避免整屏刷新

## 技术实现

- **帧循环**：主循环 + `Sleep(8)` 控制节奏，按键通过 `_kbhit()` / `_getch()` 非阻塞读取。
- **渲染**：用 `SetConsoleCursorPosition` 把光标定位到指定坐标输出字符；移动前先把旧位置擦成空格，避免整屏 `cls` 造成的闪烁。
- **对象池**：10 发子弹、8 架敌机使用定长数组管理，未激活对象以 `Y = 30` 标记，射击时复用空槽。
- **碰撞**：敌机用左上、右下两个 `COORD` 表示矩形，`judgeCoordInFrame()` 判断某个字符点是否落在矩形内。
- **难度**：`rank` 控制敌机移动的帧间隔，分数达标后 `rank` 减小，敌机移动频率提高。

## 编译运行

需要 Windows 10/11。建议使用 Windows Terminal；旧版控制台请将字体设为“新宋体”等 TrueType 字体。

### Visual Studio

1. 新建“控制台应用”项目，删除默认源文件；
2. 添加现有项 `飞机大战3.0.cpp`；
3. F5 运行即可（源码为 UTF-8，代码中已设置控制台代码页）。

命令行方式：

```bat
cl /utf-8 /EHsc "飞机大战3.0.cpp"
```

### MinGW / g++

```bash
g++ -std=c++11 -O2 "飞机大战3.0.cpp" -o plane.exe
./plane.exe
```

> 控制台窗口建议不小于 80 列 × 25 行，否则边框会折行。

## 已知限制

- 碰撞基于字符点采样，极端位置下战机边缘可能与敌机重叠但不触发判定。
- 敌机生成未做重叠检测，偶尔会出现敌机重叠。
- 重新开始通过在结算界面递归启动新局实现，连续重开次数极多会加深调用栈。
- 暂无音效（背景音乐代码保留为注释）。
